Les trois sortes de paquets

Mesures : poubelles → borne Wi-Fi → Switch → Routeur 1 → antenne 5G → Internet → Routeur 3 → serveur.
Consultation : l'entreprise interroge le serveur, qui lui répond.
Ordre de collecte : entreprise → Internet → antenne 5G → tablette du camion.

Trait plein = câble · pointillé vert = Wi-Fi · pointillé bleu = liaison radio (5G).

Équipements du réseau

WF
Borne Wi-Fi : reçoit les ondes radio des appareils sans fil (poubelles, tablette) et les transmet au switch par un câble. Un switch ne reçoit que des câbles : il lui faut une borne Wi-Fi pour recevoir les appareils sans fil.
SW
Switch (commutateur) : relie entre eux les appareils situés dans le même réseau local. Il ne change pas de réseau.
RT
Routeur : relie plusieurs réseaux entre eux. Il possède une adresse IP dans chacun d'eux (une par interface). Dans Internet, de nombreux routeurs se passent les paquets de proche en proche. Celle qui se trouve dans le réseau local est la passerelle (gateway) : c'est l'adresse à laquelle les appareils confient les paquets destinés à l'extérieur.
5G
Antenne relais : transmet les données par ondes radio entre le réseau local, Internet et les appareils mobiles (comme la tablette du camion).
SRV
Serveur de données : ordinateur qui reçoit, enregistre et met à disposition les taux de remplissage.
GST
Entreprise de gestion : consulte les données sur un tableau de bord et organise les tournées de collecte.
À savoir : les adresses commençant par 192.168, 10 ou 172.16 sont des adresses privées : elles servent à l'intérieur d'un réseau. Sur Internet, un serveur a une adresse publique. Ici, on les utilise pour simplifier le schéma.

1. Qu'est-ce qu'une adresse IP ?

C'est le numéro qui identifie un appareil sur un réseau (comme une adresse postale). Dans un même réseau, deux appareils ne peuvent pas avoir la même adresse. Une adresse IPv4 se compose de 4 nombres (de 0 à 255) séparés par des points.

2. Le masque de sous-réseau

Il indique quelle partie de l'adresse IP correspond au Réseau et quelle partie correspond à la Machine :

  • Réseau : les nombres de l'adresse qui sont en face des "255" du masque.
  • Machine : les nombres de l'adresse qui sont en face des "0" du masque.

Deux appareils sont dans le même réseau local quand leurs parties Réseau sont identiques.

3. Rôle du Routeur

Le routeur relie les réseaux : il a une interface (une adresse IP) dans chaque réseau (192.168.1.254 et 10.0.0.254) pour transférer les données de l'un à l'autre. Dans chaque réseau local, l'adresse de son interface est la passerelle. Les appareils du réseau sont reliés entre eux et au routeur par un switch.

Décomposeur IP / Masque

Cliquez sur un exemple pour observer la séparation animée :

Adresse IP : 192.168.1.10
Masque : 255.255.255.0
Séparation : 192.168.1.10
💡 Les 255 du masque désignent la partie Réseau (192.168.1) et le 0 désigne le numéro de la Machine (10).
